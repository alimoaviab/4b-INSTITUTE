# User Flow

## Step 1 - Face Verification

When the website opens:

* Open camera automatically.
* Ask for camera permission.
* Detect face.
* Capture face image.
* Save face image.

Fields:

* Roll Number
* CNIC / B-Form Number

Verification Logic:

Check Roll Number and CNIC against database.

If matched:

* Verification successful.
* Save captured face.
* Move to next step.

If not matched:

* Show error.
* Stay on current page.

* Detect tab switching.
* Detect browser minimize.
* Detect screen leaving.
