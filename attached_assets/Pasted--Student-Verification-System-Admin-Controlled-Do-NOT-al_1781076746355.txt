## Student Verification System (Admin Controlled)

Do NOT allow students to create their own records.

All student records must be uploaded by Admin before the admission test.

### Admin Student Upload Module

Admin can:

* Add single student manually
* Bulk import students via Excel/CSV
* Upload student photo
* Add Roll Number
* Add CNIC/B-Form Number
* Add Student Name
* Add Father Name
* Add Phone Number
* Add School/College
* Add Program
* Set Test Eligibility

### Verification Flow

When student visits website:

Step 1:

System opens camera automatically.

Student enters:

* Roll Number
* CNIC/B-Form Number

System searches database.

If Roll Number and CNIC match:

* Fetch pre-uploaded student record.
* Fetch admin uploaded student photo.

Then:

* Capture live webcam image.
* Compare webcam face with admin uploaded photo using AI face recognition.

### Verification Conditions

If:

Roll Number Match = TRUE

CNIC Match = TRUE

Face Match Score >= 80%

Then:

* Verification Successful
* Allow access to application form and test

Otherwise:

* Access Denied
* Show verification failed message

### Security Rules

If roll number not found:

* Block access

If CNIC incorrect:

* Block access

If face mismatch:

* Block access

If multiple faces detected:

* Block access

If no face detected:

* Block access

### Admin Dashboard Features

Admin can:

* View verification logs
* View verification attempts
* View failed attempts
* View face matching score
* View captured image
* View student login history
* Block suspicious students

### Face Recognition Data

Store:

* Admin Uploaded Photo
* Live Captured Photo
* Face Match Percentage
* Verification Date & Time
* Device Information
* IP Address
* Browser Information

### Anti Impersonation System

During test:

Every 30-60 seconds:

* Capture random webcam image
* Compare with original student photo

If face mismatch occurs multiple times:

* Generate cheating alert
* Save violation log
* Notify admin

Admin can review all captured images from dashboard.
